# Тренировки по алгоритмам (Яндекс)

Репозиторий содержит мои решения задач из тренировок по алгоритмам от Яндекса. 
Основной упор сделан на написание оптимального кода с оценкой временной сложности.

## 🛠 Стек
* **Python 3.x**
* Стандартная библиотека (`collections`, `random`)

## 📁 Реализованные алгоритмы

### 1. Метод двух указателей (`1_two_pointers.py`)
Поиск количества пар объектов, расстояние между которыми не превышает заданное значение `r`.
* **Сложность:** `O(n)`

### 2. Скользящее окно (`2_sliding_window.py`)
Поиск анаграмм (вхождений подстроки в текст). Используется структура данных `Counter` для сравнения частот символов в окне.
* **Сложность:** `O(n)`

### 3. Монотонная очередь / Deque (`3_monotonic_queue.py`)
Поиск максимума в скользящем окне заданного размера `k`. Реализовано без использования циклов `max()`, что дает линейную сложность.
* **Сложность:** `O(n)`

### 4. Стек (`4_stack.py`)
Восстановление правильной скобочной последовательности. Используется стек для проверки парности скобок.
* **Сложность:** `O(n)`

### 5. Бинарный поиск по ответу (`5_binary_search.py`)
Поиск минимально возможной разницы, при которой можно выбрать `r` групп по `c` элементов. Используется бинарный поиск по диапазону значений.
* **Сложность:** `O(n log n)`

### 6. Быстрая сортировка (QuickSort) (`6_quicksort.py`)
Реализация алгоритма быстрой сортировки с трехпутевым разбиением (обрабатывает дубликаты элементов быстрее классической версии).
* **Сложность в среднем:** `O(n log n)`
